Download the beta one file, nothing else to install

Each download is the whole game in a single program: graphics, sound, music and levels are built in. These links always fetch the latest release.

Windows

Windows 10 and 11, 64-bit. Your system

Download for Windows
  1. Unzip the file: it holds just twin-karumba.exe.
  2. Run twin-karumba.exe.
  3. If Windows says "Windows protected your PC", choose More info, then Run anyway.

macOS

macOS 11 and newer, Apple Silicon and Intel. Your system

Download for macOS
  1. Unzip the file and move Twin Karumba to Applications if you like.
  2. The first time, right-click it and choose Open, then Open again.

Linux

Any distribution, x86-64. Your system

Download for Linux
  1. Unpack it: tar xzf twin-karumba-linux-x86_64.tar.gz
  2. Run ./twin-karumba.
  3. Sound plays through PulseAudio or PipeWire, or ALSA.

Other versions

  • Every release and its notes are on the releases page.
  • Builds of the very latest code are on the build page (open a run, then Artifacts; needs a GitHub login).
  • To build it yourself, see the README: install Rust, then cargo run --release.
